Webcam Mute Hotkey

Block or allow new camera opens with a global shortcut or the tray icon. The app changes the Windows camera privacy setting and restores it when you exit.

Windows 11 · x64 · One-time purchase · English

Coming soon to Microsoft Store

Features

  • Global shortcut (default Ctrl+Alt+K) toggles the Windows camera privacy setting
  • Tray icon shows whether new camera access is blocked or allowed — click to toggle
  • Start with Windows (optional, tray only)
  • Normal exit restores camera access (Allow)
  • Fully offline — no accounts, ads, or telemetry
  • One-time purchase (local Store price)

Important limitation

This blocks new camera opens. A camera already in use can stay on until that app reopens the camera. The tray shows the Windows privacy setting, not whether the camera is recording. Some desktop apps may not honor the setting. Windows Hello is not affected.

Privacy

See the privacy policy. The app is offline, collects no data, runs only on your PC, and only changes the Windows camera-permission setting (restored on exit).
